# ⏰ Digital Clock

A simple and responsive digital clock built using HTML, CSS, and JavaScript. It displays the current time in real time and updates every second.

## 🔗 Live Demo
[View Live Demo]

## ✨ Features
- Displays current time (hours, minutes, seconds) in real time
- 12-hour format with AM/PM
- Shows current day and date
- Clean and responsive design for all screen sizes

## 🛠️ Tech Stack
- **HTML5**: structure
- **CSS3**: styling and layout
- **JavaScript (ES6)**: time logic using the `Date` object and `setInterval()`

## 🚀 How to Run Locally
1. Clone the repository
   ```bash
   git clone https://github.com/YOUR-USERNAME/YOUR-REPO.git
   ```
2. Open the project folder
   ```bash
   cd YOUR-REPO
   ```
3. Open `index.html` in your browser (or use the Live Server extension in VS Code)
